# Voice Assistant (Python)

A voice assistant that listens, speaks, and answers questions using AI.

## Features
- Tells the time and date
- Opens YouTube, Instagram, Notepad and Calculator
- Searches Google by voice
- Answers any question using the Gemini API

## Tech used
Python, pyttsx3, SpeechRecognition, Google Gemini API

## How to run
1. pip install pyttsx3 SpeechRecognition pyaudio google-genai
2. Set your GEMINI_API_KEY
3. python assistant.py
